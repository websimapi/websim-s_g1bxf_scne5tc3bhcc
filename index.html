Public/Private Key Hell

I've created an immersive cryptographic puzzle game that generates 10 unique levels with public/private key pairs, mnemonic phrases, and AI-generated riddles. Here's how it works: 1. Each level generates a simulated key pair and converts them to mnemonic phrases 2. A word is randomly removed from each public phrase 3. The missing words are sent to the AI to generate clever riddles 4. Each level's message is encrypted using the missing word as the key 5. The encrypted message contains the next level's private key 6. Players must solve each riddle to progress through the levels 7. The game state is stored in the WebsimSocket store for multiplayer support Features: - Cryptographic functions using CryptoJS - Collaborative multiplayer support - Real-time updates when players solve levels - Level locking (must complete previous level) - Clean terminal-style UI - Persistent game state - AI-generated riddles for enhanced gameplay Players must solve each riddle to reveal the missing word, which decrypts the message containing the next level's information. The game continues until all 10 levels are completed.
